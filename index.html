On the page and on the bed

Printer & pen

Mount a pen in the toolhead, tape paper to the bed, and set Z so the nib just kisses the page. Home X/Y only. Watch the first run. Custom G-code can crash a pen into the bed if Z is wrong.

Bambu Lab A1 setup

  1. Print an A1 pen holder — not a P1/X1 mount. Start with Pen Holder A1 / A1 Mini or the simpler Easy penholder. The modular UMTS by Falu also lists an A1 profile.
  2. Unload filament. Leave AMS Lite disconnected for this job. Mount the holder per its page, then clamp a fineliner. The nib sits below the nozzle — that gap is pen Z offset.
  3. Tape paper to a smooth / cool plate (textured PEI is lumpy). Put the top of the page toward the back of the printer. Keep ~25 mm clear of every bed edge. The start G-code homes the nozzle at X128 Y2 so the pen can hang off the rear — do not tape paper into that back strip.
  4. Leave pen Z offset at 20 mm for the first runs (too high is safe; too low scrapes the plate on the way in). A 2 mm click-count is almost always too small — if the Sharpie cannot clear the rear edge after Z home, the offset is too low, not Z up. Z down = 0 after that offset is zeroed.
  5. Export a dry-run first (pen stays up). Copy the .gcode to the root of the A1 MicroSD card. The card is not hot-swappable: on the screen, eject it before pulling it. Wiki: print from SD card.
  6. Print Files → your file. Turn off bed leveling, flow/nozzle calibration, AMS, and spaghetti detection if the start dialog offers them. Stay next to the machine for Z home. If the pen hits the bed before the nozzle does, abort immediately and increase the offset — or make sure Y2 actually clears the pen off the plate.
  7. When the dry-run path looks right, run the 20 mm square. Lower pen Z offset a millimeter at a time until the square is a clean line, then write a short word. Mirror X is on for the A1 so the page reads left-to-right when you pick it up with the top at the back. Uncheck it if letters are still backwards.

A1 volume is 256×256×256 mm. This sequence is the A1-Mini plotter start G-code with X/Y limits changed for the full A1 (center X128, present at Y254). Watch the first home. Do not home Z from the stock print profile with a pen mounted.

Origin is the top-left of the writing area in machine coordinates, after homing. Start with a dry-run, then the 20 mm square, then a short word. If firmware blocks cold motion, enable “allow cold extrusion” / M302 on Marlin.

A small project from Build Beyond Belief

It started with a birthday note.

I used this to make a birthday note in my own handwriting, with a pen attached to a 3D printer. Along the way, turning letters into movements became a project of its own.

That is the part I enjoy: making something personal, figuring out how to make it work, and sharing it so someone else can have a go.

Printer & pen

Same machine, different tool

A plotter moves a pen along a path. Your 3D printer already has the motion: X and Y move across the page, and Z lifts the pen between strokes. A suitable holder keeps the pen attached to the toolhead while paper stays secured to the bed.

This app turns your saved strokes into G-code, the movement instructions the printer reads. The exported job requests no nozzle or bed heat and no plastic extrusion. It does not connect to or control your printer from the browser.

You will need a compatible pen holder, a pen, paper, and a way to load the file on your printer. Presets are starting settings; the holder position, pen length, firmware, and usable travel still need checking on your machine.

You need a 3D printer — the kind that usually melts plastic — with a pen clipped where the nozzle sits, and paper taped to the bed. This site does not talk to the printer by itself. You download a print file from the Note page, then start it the same way you would start a normal print (often a memory card). Stay next to the first run. If the pen is too low it can scratch the bed.

Bambu Lab A1 is a popular small desktop 3D printer this app is tuned for. If that is your machine, pick it under Printer model. For another printer, check its firmware and dimensions against the available presets before exporting. You do not need a Bambu printer to try the on-screen note.

If your printer is a Bambu Lab A1

The A1 is a small open-frame 3D printer. Use this checklist only if you selected that model above. The pen hangs lower than the plastic nozzle, so a normal “home everything” print can drive the nib into the bed — follow these steps instead.

  1. Print an A1 pen holder — not a P1/X1 mount. Start with Pen Holder A1 / A1 Mini or the simpler Easy penholder. The modular UMTS by Falu also lists an A1 profile.
  2. Unload filament. Leave AMS Lite disconnected for this job. Mount the holder per its page, then clamp a fineliner. The nib sits below the nozzle — that gap is pen Z offset.
  3. Tape paper to a smooth / cool plate (textured PEI is lumpy). Put the top of the page toward the back of the printer. Keep ~25 mm clear of every bed edge. The start G-code homes the nozzle at X128 Y2 so the pen can hang off the rear — do not tape paper into that back strip.
  4. Measure how far the nib sits below the nozzle and use that to check pen Z offset. The default 20 mm is a starting value, not a measured clearance. The startup homes Z before applying this offset, so increasing it cannot prevent a collision during homing. Confirm the mounted pen clears the bed at the homing position before running the file.
  5. Export a dry-run first (pen stays up). Copy the .gcode to the root of the A1 MicroSD card. The card is not hot-swappable: on the screen, eject it before pulling it. Wiki: print from SD card.
  6. Print Files → your file. Turn off bed leveling, flow/nozzle calibration, AMS, and spaghetti detection if the start dialog offers them. Stay next to the machine for Z home. If the pen hits the bed before the nozzle does, stop the job. Correct the holder clearance or homing approach before trying again; changing the offset alone will not fix contact during homing.
  7. When the dry-run path looks right, run the 20 mm square. Lower pen Z offset a millimeter at a time until the square is a clean line, then write a short word. Mirror X is on for the A1 so the page reads left-to-right when you pick it up with the top at the back. Uncheck it if letters are still backwards.

The A1’s build area is 256×256 mm. Watch the first home. Do not use the stock plastic-print home with a pen mounted.

After you pick a printer, clip a fineliner in a printed pen holder, tape paper to a smooth plate, and download a practice file first (pen stays up). Then a 20 mm test square, then a short word. “Pen height while writing” is where the nib just marks the paper. “Pen height while moving” should clear the page. Home left-right and front-back only — never home the up-down axis with a pen mounted. If motion is refused, check the printer’s homing requirements and firmware documentation. This job uses no extrusion, so enabling cold extrusion is not a required setup step.

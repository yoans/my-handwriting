The printer can only replay paths you draw here — it cannot guess from a photo of letters. Draw each character the way you write it (a tablet pen is nicest; a mouse works). Save a few versions of the letters you actually use.

The four steps

  1. Write — record your letters. The printer copies these paths, in order.
  2. Stamps — optional. Turn a drawing or photo into a small picture the pen can draw on the page.
  3. Note — type a message. Download a print file for the machine, or a picture to preview.
  4. Printer — pick your 3D printer, clip a pen on it, run a practice pass with the pen in the air first.

Size, spacing, and how messy it looks

Letter height is the size of a lowercase letter like “x”. Line spacing is a multiple of that. Wobble mixes your saved versions so it does not look like a font.

The print file tells the 3D printer where to move with the pen down. The practice file does the same path with the pen lifted so you can watch without marking paper. Copy the print file onto the printer’s card or send it the way you usually start a print.

Fits on the paper and on the printer bed

Printer & pen

You need a 3D printer — the kind that usually melts plastic — with a pen clipped where the nozzle sits, and paper taped to the bed. This site does not talk to the printer by itself. You download a print file from the Note page, then start it the same way you would start a normal print (often a memory card). Stay next to the first run. If the pen is too low it can scratch the bed.

Bambu Lab A1 is a popular small desktop 3D printer this app is tuned for. If that is your machine, pick it under Printer model. If you have something else (Prusa, Ender, and many others), pick the closest match. You do not need a Bambu printer to try the on-screen note.

If your printer is a Bambu Lab A1

The A1 is a small open-frame 3D printer. Use this checklist only if you selected that model above. The pen hangs lower than the plastic nozzle, so a normal “home everything” print can drive the nib into the bed — follow these steps instead.

  1. Print an A1 pen holder — not a P1/X1 mount. Start with Pen Holder A1 / A1 Mini or the simpler Easy penholder. The modular UMTS by Falu also lists an A1 profile.
  2. Unload filament. Leave AMS Lite disconnected for this job. Mount the holder per its page, then clamp a fineliner. The nib sits below the nozzle — that gap is pen Z offset.
  3. Tape paper to a smooth / cool plate (textured PEI is lumpy). Put the top of the page toward the back of the printer. Keep ~25 mm clear of every bed edge. The start G-code homes the nozzle at X128 Y2 so the pen can hang off the rear — do not tape paper into that back strip.
  4. Leave pen Z offset at 20 mm for the first runs (too high is safe; too low scrapes the plate on the way in). A 2 mm click-count is almost always too small — if the Sharpie cannot clear the rear edge after Z home, the offset is too low, not Z up. Z down = 0 after that offset is zeroed.
  5. Export a dry-run first (pen stays up). Copy the .gcode to the root of the A1 MicroSD card. The card is not hot-swappable: on the screen, eject it before pulling it. Wiki: print from SD card.
  6. Print Files → your file. Turn off bed leveling, flow/nozzle calibration, AMS, and spaghetti detection if the start dialog offers them. Stay next to the machine for Z home. If the pen hits the bed before the nozzle does, abort immediately and increase the offset — or make sure Y2 actually clears the pen off the plate.
  7. When the dry-run path looks right, run the 20 mm square. Lower pen Z offset a millimeter at a time until the square is a clean line, then write a short word. Mirror X is on for the A1 so the page reads left-to-right when you pick it up with the top at the back. Uncheck it if letters are still backwards.

The A1’s build area is 256×256 mm. Watch the first home. Do not use the stock plastic-print home with a pen mounted.

After you pick a printer, clip a fineliner in a printed pen holder, tape paper to a smooth plate, and download a practice file first (pen stays up). Then a 20 mm test square, then a short word. “Pen height while writing” is where the nib just marks the paper. “Pen height while moving” should clear the page. Home left-right and front-back only — never home the up-down axis with a pen mounted. If the printer refuses to move while cold, look in its firmware settings for “allow cold extrusion.”
